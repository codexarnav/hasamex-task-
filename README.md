# InsightOS Platform

For complete documentation, architecture diagrams, and quickstart instructions, please refer to the [backend/README.md]

### Quick Start with Docker Compose:
```bash
cd backend
docker compose up --build
```
The API will be live at `http://localhost:8000` with Swagger UI at `http://localhost:8000/docs`.

### Running Tests:
```bash
cd backend
pytest -v
```
